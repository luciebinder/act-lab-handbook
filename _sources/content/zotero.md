# Zotero

[Zotero](https://www.zotero.org/) is a free reference management tool that helps you collect, organise, and cite literature.

## Using Zotero for Scientific Writing

Zotero integrates with Word and other writing tools to help you insert citations and generate reference lists automatically.

```{seealso}
Check out the documentation on the [word processor integration](https://www.zotero.org/support/word_processor_integration) as well as a quick overview on how to use Zotero for scientific writing from the [EXPRA course website](https://expra-frankfurt.github.io/wise25/content/writing.html#references)
```

## Browser Plugin

I strongly recommend installing the **[Zotero Connector](https://www.zotero.org/download/)** browser plugin. It allows you to save references directly from your browser to your Zotero library with a single click — including PDFs where available.
